# Predictive Hospital Triage Surge Engines
A hybrid predictive–prescriptive framework for hospital triage and resource optimization under demand uncertainty. A real-time decision support system that forecasts patient inflow and dynamically optimizes hospital resource allocation (beds, staff, triage priority).


Integrated ICU clinical data with external environmental signals (weather + epidemiological trends) to improve surge prediction accuracy.

Data Sources used in this project:
1. MIMIC Hospital Data
2. Weather Data
